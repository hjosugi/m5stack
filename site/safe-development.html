確認、保存、書込みを分ける

buildまでは実機を変更しません。Flash操作は対象を固定し、バックアップを検証してから明示フラグ付きで行います。

非破壊のセットアップ

git clone https://github.com/hjosugi/m5stack.git
cd m5stack
direnv allow
<<<<<<< HEAD
make setup
make detect
make init
./scripts/select-board.sh stackchan

Cardputer Advなら最後から2行目を./scripts/select-board.sh cardputer-advにします。

ここまではFlashしません。USB属性の確認、ローカル設定、依存導入、compileだけです。

保存先は.local/backups/<製品>/<UTC時刻>/です。Wi-Fi等を含み得るため公開しません。

確認スケッチを書き込む

工場ファームウェアを置き換えます。画面リンク用build scriptはこの操作を行いません。以下はリポジトリ標準の確認スケッチ用です。
# Cardputer Advなど
./scripts/upload.sh --allow-flash

# StackChan（追加確認あり）
./scripts/upload.sh --allow-flash --replace-factory-firmware

接続実機、製品設定、検証済みバックアップが一致しない場合は中止します。

全Flashを復旧

./scripts/grant-port-access.sh
./scripts/restore-flash.sh --allow-flash \
  .local/backups/<製品>/<UTC時刻>/flash-<容量>.bin

バックアップ時と同じ実機だけに復旧できます。途中でUSBや電源を抜かないでください。
