M5Stack / Cardputer Adv / StackChan

やることから、すぐ手順へ。

PC画面の無線リンク、Cardputerの完全mute、実機を壊しにくいビルド・バックアップ・復旧を、目的別にまとめています。

PC画面を端末へ送る 安全に開発を始める
  • 音声は送信しない
  • 2.4 GHz LAN
  • 秘密情報は.envだけ
  • buildで自動Flashしない

目的を選ぶ

1

PC画面を端末へ送る

PC relay、Cardputer、StackChanの設定場所と起動順を一ページで確認します。

2

Cardputerを確実にmuteする

speakerを初期化しない方法と、実行中に音量を0へ落とす方法を分けて掲載します。

3

実機を安全に扱う

非破壊の確認、全Flashバックアップ、書込み、復旧の境界を短く整理します。

4

エラーから探す

Wi-Fi、relay、USB、権限、StackChanの対応ファームウェアを症状別に確認します。

画面リンクの流れ

ブラウザーで選んだ画面だけをJPEG化します。マイクやPC音声は取得しません。

PCブラウザー画面を選ぶ
→
PC relay認証して中継
→
端末JPEGを表示
このreleaseはbuildまでです。 Cardputer／StackChanへ自動でFlashしません。既存ファームウェアを置き換える前に、復旧経路と全Flashバックアップを用意してください。

最初の3コマンド

Nixとdirenvが導入済みなら、開発環境はリポジトリ内だけに作られます。

git clone https://github.com/hjosugi/m5stack.git
cd m5stack
direnv allow
