Screen Link

PC画面をCardputer／StackChanへ送る

同じLAN上で、ブラウザーが選んだ画面またはウィンドウだけを送ります。音声は送りません。

  • 設定場所
  • PC
  • Cardputer
  • StackChan
  • 起動
  • 確認
先に確認 build scriptは実機へFlashしません。端末へ導入する前に、全Flashバックアップと復旧方法を確認してください。

どこに何を書く？

3つの.env.exampleを同じ場所の.envへコピーします。tokenは3か所すべて同じ値です。

場所書くもの実行するもの
pc/screen-link/.envport、共通tokenrun.sh
cardputer/screen-link/.envWi-Fi、PCのLAN IP、共通tokenbuild.sh
stackchan/screen-link/.envPCのLAN URL、共通tokenbuild.sh

公開しない: .env、Wi-Fi password、token、.local/の成果物。

  1. PC relayを設定

    例をコピーし、tokenを一度だけ生成します。

    cp pc/screen-link/.env.example pc/screen-link/.env
openssl rand -hex 24

    生成値をpc/screen-link/.envのSCREEN_LINK_TOKEN=の右へ貼ります。

    SCREEN_LINK_HOST=0.0.0.0
SCREEN_LINK_PORT=8765
SCREEN_LINK_TOKEN=ここへ生成値

  2. Cardputer Advを使う場合

    2.4 GHz Wi-Fi、PCのLAN IP、PCと同じtokenを書きます。

    cp cardputer/screen-link/.env.example cardputer/screen-link/.env
make setup
make build-cardputer-screen-link

    成果物は.local/build/cardputer-screen-link/です。speakerは既定で初期化されません。

    設定の目印SCREEN_LINK_SERVER_HOSTは192.168.x.x等のPCのLAN IPです。127.0.0.1ではありません。

  3. StackChanを使う場合

    公式1.4.3系のAVATAR画面リンク用です。PCのLAN URLと同じtokenを書きます。

    make setup-stackchan
cp stackchan/screen-link/.env.example stackchan/screen-link/.env
make build-stackchan-screen-link

    成果物は.local/build/stackchan-screen-link-ja/です。

    対応を確認コミュニティ版v1.0.0には同じ受信経路がありません。このscriptは実機のファームウェアを自動変更しません。

  4. PCから送信

    relayを起動し、PC自身のブラウザーで画面を選びます。

    ./pc/screen-link/run.sh
    1. http://127.0.0.1:8765/を開く。
    2. 同じtokenを入力する。
    3. 送信先を選び「画面共有を開始」を押す。
    4. ブラウザーのダイアログで共有範囲を確認する。

    終了はブラウザーの「停止」またはterminalのCtrl-Cです。

つながったか確認

PCで/healthzを開きます。接続済み端末が1ならrelayまで到達しています。

{"status":"ok","producers":1,"cardputer":1,"stackchan":0}
  • producers: 1 — ブラウザーが送信中
  • cardputer: 1 — Cardputerが接続中
  • stackchan: 1 — StackChanが接続中

状態欄の破棄は異常終了ではありません。ネットワークが追いつかないとき、遅延を溜めないため古いframeを捨てた数です。
